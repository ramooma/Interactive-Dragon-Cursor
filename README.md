# 🐉 Interactive Dragon Cursor

### A creative and interactive custom SVG cursor that follows mouse movements!

## 📌 Project Overview
This project replaces the default browser mouse pointer with a dynamic, fully animated Dragon cursor. Built using **SVG (Scalable Vector Graphics)** and interactive web technologies, the dragon fluidly follows the user's mouse movements across the screen.

It showcases an understanding of custom DOM manipulation, mouse event tracking, and advanced SVG rendering to create a highly engaging micro-interaction.

## 🚀 Key Features
- **Custom Mouse Tracking:** The dragon cursor accurately tracks and follows the real-time `x` and `y` coordinates of the user's mouse.
- **Advanced SVG Graphics:** Utilizes scalable and lightweight SVG paths to render the intricate details of the dragon without losing quality.
- **Smooth Animation:** Ensures fluid motion and rotation to make the dragon feel "alive" as it navigates the webpage.
- **Creative UI/UX:** Adds a unique and playful element to standard web browsing.

## 🛠️ Tech Stack
- **HTML5:** For the core structure and embedding the SVG.
- **CSS3:** For styling, hiding the default cursor, and layout adjustments.
- **JavaScript:** (Used for tracking mousemove events and updating SVG coordinate logic).
- **SVG:** For rendering the dragon's head, spine, and tail.
